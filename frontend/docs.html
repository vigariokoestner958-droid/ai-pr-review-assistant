X-Reviewer API

AI PR 代码审查服务接口文档 · Base URL: http://localhost:8001

核心接口
POST /analyze
分析一个 GitHub PR，返回风险列表、评分和审查意见。

请求体（JSON）

pr_urlstringGitHub PR 地址，例如 https://github.com/owner/repo/pull/1

请求示例

curl -X POST http://localhost:8001/analyze \
  -H "Content-Type: application/json" \
  -d '{"pr_url": "https://github.com/owner/repo/pull/1"}'

响应示例

{
  "summary": {
    "what_changed": "新增用户登录功能",
    "change_type": "feature",
    "core_change": "添加了 JWT 认证逻辑",
    "affected_modules": ["auth", "api"]
  },
  "risks": [
    {
      "severity": "HIGH",

POST /feedback
提交用户反馈（有帮助 / 没帮助），用于监控有帮助率指标。

请求体（JSON）

pr_urlstring被分析的 PR 地址
votestringup 或 down
commentstring?可选，补充说明
监控接口
GET /api/metrics
返回过去 7 天的监控数据（JSON），包含 KPI、告警、趋势、评分分布和最近记录。

请求示例

curl http://localhost:8001/api/metrics
GET /stats
监控看板页面（HTML），可视化展示所有监控指标。
GET /health
健康检查接口，返回 {"status": "ok"}。
