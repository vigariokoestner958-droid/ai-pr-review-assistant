# AI PR Review 助手 (AI PR Review Assistant)

## 项目简介
本项目是为“七牛云 × XEngineer 暑期实训营”开发的 AI 代码审查工具。
旨在帮助开发者提升 Pull Request 的 Review 效率与质量。本工具利用大语言模型（LLM）自动获取 GitHub PR 的代码变更，进行智能分析，并提供代码总结、风险识别和 Review 建议。

## 功能特性
- [ ] **PR 变更总结**：自动提炼 PR 的核心修改内容。
- [ ] **风险代码识别**：检测潜在的 Bug、安全漏洞或性能问题。
- [ ] **Review 建议生成**：提供代码优化和重构建议。
